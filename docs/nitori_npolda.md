## 実績のある取付部品（`src/pegboard/mount.py`）

### 曲げロッドフック `bent_hook()`

φ5 のロッドを穴に通し、ボードの裏で R8・60° だけ上へ曲げる。ロッドが穴の底に乗った状態で、
曲げの内側が穴の裏側の縁にちょうど当たる（`lip_gap` = 0.05 mm）ように、ボード内の直線部の
長さ（約 2.39 mm）を決めている。こうすると部品がボードから浮かない。

この形が「傾けて差し込み、起こして掛ける」動きで干渉しないことは `tools/insertion_sim.py`
で確認済み（HUB75 レールで印刷・装着も済み）。

`flat_width` を指定すると、ロッドを |x| ≤ flat_width/2 で切り落とした D カット断面になる。
y-z 面内の形状は丸ロッドと同じなので、挿入性の検証結果はそのまま使える。横倒しで印刷すれば
曲げ部が積層面内に入るため、ロッドを立てて印刷するより曲げに強い。

### 直ペグ `straight_peg()` / 圧入ペグ `press_fit_peg()`

- `straight_peg`: フックの下の穴に入れる回り止め。穴の中心に置き、先端を面取りする。
- `press_fit_peg`: φ6.1 にスリットを入れた軽圧入ペグ。HUB75 の下側レールで使ったもの。
  丸ペグはスリットが縦で、立てて印刷する。`flat_width` を指定すると D カットになり、上下の円弧
  だけが穴に当たるのでスリットを横にする。横倒しで印刷すると、爪が積層面内でたわむ。
