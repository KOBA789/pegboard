# iPad Pro 11 ホルダー

iPad Pro 11 インチ（第 3 世代、M1、2021）を横向きで、ボードのすぐ前に置くホルダー。画面は部屋側に向け、USB-C は右に出る。
右から差し込んで左へ滑らせると、左端のストッパーに当たって止まる。抜くときは、ボードの右端からはみ出した右の辺をつまんで右へ引く。

| 部品 | モジュール | 印刷 |
|---|---|---|
| ストッパー（左） | `holder.py` の `stop()` | `output/stop.stl` ×1 |
| レール（右） | `holder.py` の `rail()` | `output/rail.stl` ×数個（下記） |

```sh
uv run python -m hooks.ipad_pro_11.build   # output/ に出力
```

## iPad の寸法（`ipad.py`）

| 項目 | 値 | 出典 |
|---|---:|---|
| 幅 × 高さ × 厚み | 247.6 × 178.5 × 5.9 mm | Apple 公称 |
| 重量 | 466 g（Wi-Fi）。Apple Pencil（第 2 世代）が 21 g | Apple 公称 |
| 画面の縁 | 約 8.9 mm | 推定（2388 × 1668 px、264 ppi から逆算した表示部 229.8 × 160.5 mm） |
| 背面カメラの出っ張り | 1.5 mm、31 mm 角、左と上の辺から 8 mm（正面から見て左上） | 推定。未実測 |

- 向きは USB-C が右になるようにする。このとき、Apple Pencil は上の辺に付き、前面カメラは左の縁に、背面カメラは正面から見て左上の裏に来る。
- 干渉チェック用のモデルは、稜線を R0.5 で丸めた箱。実物の丸みより小さく見積もった値。

## 設計

### 構成

| 部品 | 何をするか |
|---|---|
| ストッパー | iPad の左下を受ける。下の辺の溝と、左の辺の溝がある。左の溝の横の壁がストッパーで、iPad はここに当たって止まる |
| レール | 下の辺の溝だけ。両端が開いているので、iPad を右から通して滑らせる。1 個だけだと、差し込む途中で iPad の左が落ちて不便だった。そのため、ストッパーとの間にも同じ段で何個か並べる（モデルとテストは右端の 1 個だけを扱う） |

- 下の辺の手前にはリップ（高さ 6 mm）があり、下端が手前に蹴り出されるのを止める。左の辺の手前にもリップ（縁にかかるのは 6 mm）があり、上が手前に倒れるのを止める。
- どちらのリップも画面の縁（推定 8.9 mm）の内側にあるので、画面にはかからない。
- 板のような iPad の下の辺と左の辺の 2 本の線が押さえられているので、右上の角も手前に出てこられない。
- 外すには、右へ引き抜くか、6 mm 持ち上げて下の溝から出すかしかない。
- 上の辺（Apple Pencil）と右の辺（USB-C）には何も触れない。

テスト（`tests/test_ipad_pro_11.py`）で、次のことを確かめている。

- iPad を手前に 1 mm 動かす、上を 1° 手前に倒す、右端を 1° 手前に振る。このどれをやっても受け皿と干渉する。
- 右へ 300 mm まで引き抜く間、ストッパーにもレールにも当たらない。

### ボードに近づけるために

iPad の背面は、両部品の板（厚さ 3.5 mm）に当たる。iPad のいちばん前（リップの前面）は、ボードから 12.6 mm。
背面カメラの出っ張り（推定 1.5 mm）とボードの間には 2 mm 残る。ストッパーの板の上端は、カメラより下で止めてある。

### ストッパーの壁は左の辺の中央だけに当てる

左の辺（縦向きにしたときの上の辺）には、スピーカーの穴と、上の角の近くにトップボタンがある。
横の壁は、下の辺から 79〜99 mm（左の辺の中央 ±10 mm）だけに残し、ほかは窓にして開けてある。
**スピーカーとボタンの正確な位置は確かめていない**。実物と合わせて `pad` を直す。

### 寸法

| パラメータ | 値 | 意図 |
|---|---:|---|
| 板の厚み `plate_t` | 3.5 mm | iPad の背面とボードの間隔。カメラの出っ張りに余裕を足した値 |
| 溝の幅 `gap` | 厚み + 0.8 mm（6.7 mm） | FDM では内寸が 0.1 mm ほど小さく出る。滑りが渋ければ広げる |
| 下のリップの高さ `lip_h` | 6 mm | 画面の縁の内側 |
| 左のリップの幅 `lip_w` | 6 mm | 同上 |
| リップの厚み `lip_t` | 2.4 mm | 0.4 mm ノズルで 6 本 |
| 床の厚み `floor_t` | 4 mm | |
| 間隔 `spacing` / `stop_rows` | 8 ピッチ右、3 ピッチ下 | レールのフックはストッパーのフックの 8 つ右、3 つ下の穴に掛ける。床の高さは両方で同じになる |
| 幅 | ストッパー 26 mm、レール 20 mm | フック/ペグの列を中心に左右対称 |
| 稜線 `r_soft` | R0.8 | リップの厚みの半分より小さくする |

- レールは、フックを (0, 0)、ペグを 1 つ下の穴に入れる。ストッパーは、フックを (0, 0)、ペグを 3 つ下の穴（レールのフックと同じ段）に入れる。部品はほかのホルダーと同じ。
- iPad の右の辺は、レールのフックの列から 37.6 mm 右にある。ボードの端が最後の穴の中心から 12.5 mm（推定。実測していない）なら、ボードから約 25 mm はみ出すので、そこをつまめる。
- 荷重は iPad と Pencil で約 4.8 N を 2 個で受ける。重心がボードから約 6.5 mm しか離れていないので、フックを引く力はごく小さい。

稜線の丸め:
- レールは 1 つの断面の押し出しなので、`soft_extrude` で丸めている。
- ストッパーは 2 方向の溝と窓がある形なので、`soft_fillet` で丸めている。窓の切り口と溝の内隅のフィレットが交わるところでフィレットが失敗した。そのため、ストッパーの溝の内隅は角のまま残している。

挿入性: どちらの部品も、フックとペグを同時に考えた場合について `tools/insertion_sim.py` で OK を確認した（コマンドは同ファイルの docstring にある）。

## 印刷

- STL は -x 面（左の側面）を下にして置いてあるので、そのまま印刷する。フックの曲げが積層面内に入る。
- **フックとペグの下だけサポートが必要**。
- 溝の幅は試し刷りで確かめるとよい（レールは小さいので試しやすい）。
- 壁 3 周以上、インフィル 30 % 以上を推奨。

## 取り付けと使い方

1. レールを、ボードのいちばん右の列の穴に掛ける。本体を傾けてフックを差し込み、起こしてペグを 1 つ下の穴に押し込む。
   残りのレールは、同じ段で、ストッパーとの間の列に掛ける。差し込む途中で iPad の左が落ちないようにするため。
2. ストッパーを、レールのフックから 8 つ左、3 つ上の穴に掛け、ペグを 3 つ下の穴（レールのフックと同じ段）に押し込む。
3. iPad は、USB-C を右、画面を手前にして持つ。下の辺をレールの右端から溝に入れ、ストッパーに当たるまで左へ滑らせる。
4. 充電ケーブルは右から挿す。L 字のプラグを使うと、横への出っ張りと差込口への負担が減る。
5. 外すときは、右の辺をつまんで右へ引き抜く。
